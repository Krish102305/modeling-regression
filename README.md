# Modeling - regression: used car prices (buy or pass at auction)

Code that reproduces every number in the write-up for this assignment.

- `regression.py`: the full analysis. Run `python regression.py` from this folder.
- `used_car_sales.csv, auction_lots.csv`: the CSV data provided with the assignment
- `regression_output.txt`: the script's printed output
- `pred_vs_actual.png`: figure produced by the script

Requires: pandas, numpy, scikit-learn, statsmodels, matplotlib. Random seed fixed at 42.
